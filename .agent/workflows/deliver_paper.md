# /deliver_paper Workflow

This workflow automates the final delivery of `ACADEMIC_PAPER.html` and prepares it for an external secondary review by ChatGPT.

### 1. Execute the Automation Script
Run the following command in your terminal. This will verify the paper, send it to your Telegram, and generate the analysis prompt.

// turbo
```powershell
powershell -ExecutionPolicy Bypass -File .\finalize_and_sync.ps1
```

### 2. Standardized ChatGPT Review
Once the file is on your phone/computer via Telegram:
1. Upload the `ACADEMIC_PAPER.html` file to **ChatGPT (GPT-4o)**.
2. Paste the standardized "Reviewer Prompt" generated by the script.
3. Compare the ChatGPT feedback with the internal `supervisor_defense_guide.md` to ensure your defenses are solid.

### 3. Final Verification
- [ ] Verify the file was received correctly on Telegram.
- [ ] Confirm the PDF export maintains the final IEEE formatting.
- [ ] Review the `walkthrough.md` for the final quality check.
